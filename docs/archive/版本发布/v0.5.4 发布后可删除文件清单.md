## 1. 前置说明

本清单只覆盖本仓库内、本轮发布产生的构建产物、验证日志、烟测残留与缓存目录。

删除前必须逐项人工确认：

- 目标路径确实位于 `E:\project\star-sanctuary\artifacts\` 或当前仓库文档目录内
- `release-light` 附件已经成功挂到 GitHub Release
- `Portable Full` / `Single-Exe Full` 已由开发人员手动发布到官网，且下载可用
- 不再需要保留当前轮次的本地复核材料、日志或中间缓存

禁止写入本清单的默认可删范围：

- 用户主目录
- `%LOCALAPPDATA%` 广域路径
- `C:\Users\admin\.star_sanctuary-bootstrap`
- 任意真实状态目录或用户数据目录
